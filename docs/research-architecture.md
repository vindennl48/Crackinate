## Overview

This document covers the recommended technology stack, project architecture, menu bar app structure, and persistence strategy for Crackinate — a macOS menu bar app that prevents screen sleep and lid-close sleep, with timer and settings support.

---

## Technology Recommendation

### Language: Swift (100%)

Swift is the only practical choice. macOS power management APIs (IOKit, pmset) have no viable cross-language bindings. Every successful open-source keep-awake app on macOS is written in Swift or Objective-C.

### UI Framework: SwiftUI with MenuBarExtra (macOS 14+ recommended)

| Approach | Pros | Cons |
|----------|------|------|
| **MenuBarExtra (SwiftUI)** | Dead simple, no AppDelegate, built-in Settings scene | Less control over dynamic icon, macOS 13+ only |
| **NSStatusItem (AppKit)** | Full control over button, icon, click behavior | More boilerplate, requires AppDelegate |

**Recommendation:** Use **AppKit NSStatusItem + NSPopover with SwiftUI views** for maximum control and macOS version compatibility. This is the approach used by SleepOff, muxbar, and most production menu bar apps.

Minimum deployment target: **macOS 14 (Sonoma)** to get SMAppService without deprecation warnings.

### Key Frameworks

| Framework | Purpose |
|-----------|---------|
| `IOKit.pwr_mgt` | Power assertions (screen sleep prevention) |
| `Foundation` | NSProcessInfo (higher-level sleep prevention), Process (pmset/caffeinate) |
| `ServiceManagement` | SMAppService (login item registration) |
| `SwiftUI` | UI views, settings |
| `AppKit` | NSStatusItem, NSPopover, NSApplication delegate |

## Menu Bar Architecture

### Entry Point

```swift
// CrackinateApp.swift
import SwiftUI

@main
struct CrackinateApp: App {
    @NSApplicationDelegateAdaptor(AppDelegate.self) var appDelegate
    
    init() {
        // Register all UserDefaults defaults before any view reads them
        UserDefaults.standard.register(defaults: [
            "screenAwakeEnabled": false,
            "lidSleepDisabled": false,
            "timerDuration": 0,        // 0 = forever
            "launchAtLogin": false,
            "dimDisplayWhenLidClosed": false,
            "showThermalWarnings": true
        ])
    }
    
    var body: some Scene {
        Settings {
            SettingsView()
        }
    }
}
```

### AppDelegate (Status Bar Item)

```swift
// AppDelegate.swift
import Cocoa
import SwiftUI

class AppDelegate: NSObject, NSApplicationDelegate {
    private var statusItem: NSStatusItem!
    private var popover: NSPopover!
    private let keepAwake = KeepAwakeManager.shared
    
    func applicationDidFinishLaunching(_ notification: Notification) {
        // Hide from Dock
        NSApp.setActivationPolicy(.accessory)
        
        // Create status bar item
        statusItem = NSStatusBar.system.statusItem(
            withLength: NSStatusItem.variableLength
        )
        
        if let button = statusItem.button {
            updateIcon(button: button)
            button.action = #selector(togglePopover)
            button.target = self
        }
        
        // Create popover
        popover = NSPopover()
        popover.contentSize = NSSize(width: 280, height: 320)
        popover.behavior = .transient
        popover.contentViewController = NSHostingController(
            rootView: ContentView()
        )
        
        // Handle app termination cleanup
        NotificationCenter.default.addObserver(
            self,
            selector: #selector(cleanupOnTerminate),
            name: NSApplication.willTerminateNotification,
            object: nil
        )
    }
    
    @objc private func togglePopover(_ sender: Any?) {
        guard let button = statusItem.button else { return }
        if popover.isShown {
            popover.performClose(sender)
        } else {
            popover.show(
                relativeTo: button.bounds,
                of: button,
                preferredEdge: .minY
            )
            popover.contentViewController?.view.window?.makeKey()
        }
    }
    
    func updateIcon(button: NSStatusBarButton) {
        let isAwake = keepAwake.isActive
        let imageName = isAwake ? "moon.fill" : "sun.max.fill"
        button.image = NSImage(
            systemSymbolName: imageName,
            accessibilityDescription: isAwake ? "Active" : "Inactive"
        )
    }
    
    @objc private func cleanupOnTerminate() {
        keepAwake.disableAll()
    }
}
```

## Persistence Strategy

### Settings (UserDefaults)

Use `@AppStorage` in SwiftUI views, `UserDefaults.standard` elsewhere:

```swift
// Keys as constants to avoid typos
enum SettingsKeys {
    static let screenAwakeEnabled = "screenAwakeEnabled"
    static let lidSleepDisabled = "lidSleepDisabled"
    static let timerDuration = "timerDuration"
    static let launchAtLogin = "launchAtLogin"
    static let dimDisplayWhenLidClosed = "dimDisplayWhenLidClosed"
    static let showThermalWarnings = "showThermalWarnings"
}

// In SwiftUI views:
@AppStorage(SettingsKeys.timerDuration) private var timerDuration = 0

// In service code:
let enabled = UserDefaults.standard.bool(forKey: SettingsKeys.screenAwakeEnabled)
```

### Auto-Launch at Login (macOS 13+)

```swift
import ServiceManagement

func setLaunchAtLogin(_ enabled: Bool) throws {
    if enabled {
        try SMAppService.mainApp.register()
    } else {
        try SMAppService.mainApp.unregister()
    }
}

func isLaunchAtLoginEnabled() -> Bool {
    SMAppService.mainApp.status == .enabled
}
```

**Important:** SMAppService requires user consent. On first enable, macOS shows a notification. User can also manage this in System Settings → General → Login Items.

### Auto-Revive if Killed

Install a user LaunchAgent at `~/Library/LaunchAgents/com.crackinate.app.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.crackinate.app</string>
    <key>ProgramArguments</key>
    <array>
        <string>/Applications/Crackinate.app/Contents/MacOS/Crackinate</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <dict>
        <key>SuccessfulExit</key>
        <false/>
    </dict>
    <key>ThrottleInterval</key>
    <integer>5</integer>
</dict>
</plist>
```

- `KeepAlive → SuccessfulExit → false`: Only restart if crashed (non-zero exit). Clean quit (user chooses Quit) won't restart.
- `ThrottleInterval`: 5-second delay between restart attempts to prevent crash loops.

The app should manage this plist programmatically:
- On first launch with "launch at login" enabled: write the plist and `launchctl load` it
- If user disables "launch at login": `launchctl unload` + delete plist

### What Persists Across Reboots

| Feature | Persists? | Mechanism |
|---------|-----------|-----------|
| Screen sleep assertion | **No** | Must be recreated on each launch (IOPMAssertion is process-scoped) |
| Lid-close sleep disabled | **Yes** | `pmset disablesleep` is kernel-level, survives reboots |
| App auto-launch | **Yes** | SMAppService + LaunchAgent |
| User settings | **Yes** | UserDefaults |
| Timer state | **No** | Must be recreated on launch; if app was killed mid-timer, timer is lost |

**Critical implication:** If the app sets `pmset disablesleep 1` and then the app is killed/rebooted, the lid-close sleep remains disabled. The app MUST check this on launch and restore the expected state, or warn the user.

## Safety Architecture

### Thermal Monitoring

```swift
import Foundation

class ThermalMonitor {
    static let shared = ThermalMonitor()
    
    func startMonitoring() {
        NotificationCenter.default.addObserver(
            self,
            selector: #selector(thermalStateChanged),
            name: ProcessInfo.thermalStateDidChangeNotification,
            object: nil
        )
    }
    
    @objc private func thermalStateChanged() {
        let state = ProcessInfo.processInfo.thermalState
        switch state {
        case .nominal, .fair:
            break // OK
        case .serious:
            // Warn user
            showThermalWarning()
        case .critical:
            // Force disable keep-awake
            KeepAwakeManager.shared.disableAll()
            showCriticalAlert()
        @unknown default:
            break
        }
    }
}
```

### Lid State Polling

```swift
class LidDetector {
    private var timer: Timer?
    var onLidClosed: (() -> Void)?
    var onLidOpened: (() -> Void)?
    
    func startPolling(interval: TimeInterval = 2.0) {
        timer = Timer.scheduledTimer(withTimeInterval: interval, repeats: true) { [weak self] _ in
            self?.checkLidState()
        }
    }
    
    private func checkLidState() {
        let service = IOServiceGetMatchingService(
            kIOMasterPortDefault,
            IOServiceMatching("AppleClamshellState")
        )
        guard service != 0 else { return }
        defer { IOObjectRelease(service) }
        
        let result = IORegistryEntryCreateCFProperty(
            service,
            "AppleClamshellState" as CFString,
            kCFAllocatorDefault, 0
        )
        guard let dict = result?.takeRetainedValue() as? [String: Any],
              let closed = dict["ClamshellState"] as? Bool else { return }
        
        // Compare with previous state to detect changes
        if closed && !wasClosed { onLidClosed?() }
        if !closed && wasClosed { onLidOpened?() }
        wasClosed = closed
    }
    
    private var wasClosed: Bool = false
}
```

## Common Pitfalls

1. **App Sandbox:** If targeting Mac App Store, sandbox prevents `pmset` and IOKit writes. This app cannot be distributed through the Mac App Store. Distribute via direct download or Homebrew cask.

2. **Code Signing:** For distribution, the app must be signed and notarized. The sudoers file + pmset approach works with notarized apps.

3. **pmset Persistence:** `disablesleep 1` survives reboots. The app MUST track its own state and sync with the actual pmset state on launch.

4. **Multiple Keep-Awake Apps:** If Amphetamine, Caffeine, or similar apps are running simultaneously, assertions can conflict. Document this.

5. **Battery Drain:** Lid-close sleep prevention on battery drains fast (full system awake). Implement AC power check and warn users.

6. **Overheating in Bag:** If user enables lid-close sleep prevention and puts Mac in bag, no ventilation → thermal damage. Implement thermal monitoring as a hard safety net.
